# Centinela-WP
CentinelaWP: plugin de seguridad todo en uno para WordPress. Antivirus con seis modos de escaneo, cortafuegos, verificación en dos pasos, límite de intentos de login, copias de seguridad, integridad de archivos y roles, avisos por email, Telegram o Discord. Todo desactivado de fábrica: tú decides qué activar, con un asistente que lo explica.
